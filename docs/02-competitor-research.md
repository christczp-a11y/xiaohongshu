# 02 · 对标博主研究（用 xiaohongshu-mcp，只读）

目的：用数据回答三件事——**这个赛道有没有人做 / 做得好的怎么做 / 同粉丝量级的账号表现是什么水平**（后者用来定 20 篇实验的止损线）。

## 先说边界

- 只用读类工具：`check_login_status`、`search_feeds`、`get_feed_detail`、`user_profile`、`list_feeds`。
- 不用 `post_comment_to_feed`、`reply_comment_in_feed`、`like_feed`、`favorite_feed`、`publish_*`。
- 节奏：慢、少。我的保守建议是一天几十次以内、手动触发、不循环批量。**这是我的经验性建议，不是平台公布的阈值**，平台没有公开这个数。
- 在你自己的电脑上跑，不要在云端容器里登录（见 `05-setup.md`）。
- 工具参数以你本地 `tools/list` 返回的 schema 为准，我没有在你的环境里实际调用过。

## 搜索词（按赛道层次）

| 层 | 关键词示例 | 想知道什么 |
|---|---|---|
| 形式 | 简笔画猫 / 猫咪简笔画 / notion风 插画 / 手绘 干货卡片 | 形式有没有被做烂，头部长什么样 |
| 题材 | 避坑 / 性价比 / 人生指南 / 反常识 / 省钱 / 防骗 | 同题材谁在做、有没有标证据 |
| 交叉 | 猫 + 干货 / 猫咪 科普 / 简笔画 + 避坑 | 交叉位有没有空位 |
| 变现 | 模板 / 清单 / 贴纸 / 表情包 | 同类账号卖什么、怎么卖 |

## 每个候选账号记什么

写进 `research/benchmarks.csv`（表头已建好）：

`handle, 粉丝数, 笔记数, 形式(猫/真人/纯文字), 题材, 近10篇点赞中位, 近10篇收藏中位, 近10篇评论中位, 标题套路, 封面套路, 有无商业标识/带货, 变现路径(推测), 备注`

**关键指标：收藏/点赞比，和互动/粉丝比。** 收藏高说明"有用"，这类内容（避坑/清单）本来就该收藏高；点赞高收藏低多半是情绪/颜值内容。

## 分析模板（做完 15–20 个账号后写 `research/findings.md`）

1. 赛道热度：同形式 + 同题材的账号有几个？头部多大？
2. 同量级基线：粉丝 1k–5k 的账号，近 10 篇收藏中位数是多少 → **这就是你 20 篇实验的参照线**。
3. 标题/封面共性：前 10 名的前 8 字、用没用数字、用没用感叹。
4. 空位：没人做的组合是什么？
5. 变现证据：谁真的在接商单/卖东西，从笔记里能看到什么。**看不到的就写"未知"，别推测成事实。**

## 注意

- 小红书上的数据是账号当时的快照，会变；表里记采集日期。
- 采样偏差：搜索排序偏向高互动笔记，只看搜索结果会高估赛道。要同时看 `user_profile` 里的全部笔记。
- 别抄具体文案和图。研究的是结构，不是内容。
