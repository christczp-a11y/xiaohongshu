# 08 · 当前路线（现行，2026-10-06 整理）

> 这是**唯一有效**的路线文档。每一次路线变更的来龙去脉（含已被推翻的版本）见 `docs/archive/08-route-history-2026-10-05.md`。

## 一句话
**一个小红书图文账号：用动物的第一人称口吻，给容易紧张的人送一个能带走的心态。** 频道是**心理抚慰，不是科普**；真诚和共鸣第一。

## 已定决策
| 决策 | 内容 |
|---|---|
| 频道性质 | 心理抚慰。每篇只送**一个心态**（例："拒绝，不需要一个很好的理由""今天没成，不代表我不行"） |
| 读者 | 容易紧张、社会焦虑的人；不愿听"老人说教" |
| 叙述形式 | **第一人称动物口吻，叙述者是该篇的主角物种**（"我是一只猫/乌龟……"）。"从动物身上学到什么"是内容核心 |
| 账号头像与产品基座 | 猫（用户自己养猫）。不设固定主持团；产品以"猫 + 情绪表情"为基座，各物种插画只作内容 |
| 严谨度 | **小红书不是科学媒体**：分三档，见下。真诚底线不放宽 |
| 写稿流程 | Viral Writer 构思 → humanizer-zh 修订（含过滤规则），见下 |
| 初期目标 | **每月到手 ¥500**（长期愿景一千几百，不是上万） |
| 节奏 | 每周 3 更，12 篇 / 4 周做首轮测试 |
| 图片 | **AI 出图**（用户在本机用 Codex）。**现阶段是文字阶段，不出图** |
| 画风原则 | 铅笔线稿、米白纸、寥寥几笔、靠表情传情、大量留白（取原则，不写在世艺术家的名字） |
| 收款 | 大陆收款渠道已打通（用户陈述，我未验证） |
| 标注 | AI 辅助创作按平台要求主动标注；文末标明"（动物）的口吻（拟人）" |

## 读者与价值
- 每篇的机制：**分享"我是这样过日子的" + 给一个许可**（"你也可以……""歇一会儿，不丢人"），不讲道理，不下命令。
- 动物是**同路人**，不是老师。
- **怎么验证**：12 篇测试里看评论。"原来不止我"这类反应才是价值信号，"好可爱"不算。

## 内容形态
- 一篇一个核心观点；**每页一个意思**；卡片 5–7 页：封面 → 3 个心态页 → 陪伴页 → 提问页；末页小字标注。
- 标题 ≤ 20 字，关键词前置；正文可以很短（约 130–300 字，卡片承担内容）；互动用**填空式/低门槛提问**（"你今天做了哪一件事？一件就够"），不求赞。
- 参考帖（用户提供）给的启发：编号小标题、"具体场景 → 心态 → 许可"、关键句高亮、短标题。**它是用来理解"向动物学什么"的，不是画风参考。**
- 现有样稿：`content/posts/cat-voice-v4.md`（猫）、`content/posts/turtle-voice-v5.md`（乌龟）。

## 严谨度分档
| 档 | 内容 | 要求 |
|---|---|---|
| 1 | 心态分享（动物口吻，说"我"） | 不需要来源；标明"（动物）的口吻（拟人）；AI 辅助创作" |
| 2 | 日常常识级的习性（不想被摸就走开、乌龟缩进壳里） | 可直接写；**不写"所有猫都……""科学证明……"**；最好是用户自家动物真实有的 |
| 3 | 出现"研究发现/数据显示/科学家说" | **必须是真的并标来源**（作者 年份 期刊）；读过原文；走故事卡（`content/animal/TEMPLATE.md`）和来源日志（`research/sources_log.csv`）；不凭记忆写 DOI、论文题目、数字 |

**不放宽的**：
- 不替用户编亲身经历，不为"真实感"编细节；暗示用户家的动物真实做过的事，必须真实发生过。
- **对敏感人群的边界**（与严谨度无关，是关怀和平台风险）：不写疗效（治愈/抚平焦虑/缓解社交焦虑症），不诊断，不碰自伤自杀话题（放求助信息前核实热线有效）；不用恐惧/紧迫/优越/争议类情绪触发；避免血腥的排挤/猎杀细节。
- 不给宠物饲养、护理、医疗建议。
- "缩回壳里/看向别处"这类内容，必须同时给"歇够了再出来"，避免被读成鼓励回避（我没有核对过临床依据，是提醒）。

## 写稿流程
1. **读者要的心态**（先定）→ 2. 对应的**动物习性**（常识级或用户真实观察）→ 3. 按 **Viral Writer**（nashsu/Viral_Writer_Skill）构思出稿 → 4. 按 **humanizer-zh**（op7418/humanizer-zh，MIT）修订 → 5. 自查：无疗效、无编亲历、无"所有X都……" → 6. 写出图提示词 → 7. 用户确认 → 8. **手动发布**。
- Viral Writer 的过滤：**不用**恐惧/紧迫/优越/争议触发；不为"真实感"编亲历；无真实来源不用数据/权威策略；不照搬"emoji 做段落标记"（这个频道要安静，是判断不是数据）。该仓库**没有 LICENSE**，所以只用方法，不复制文件。
- humanizer 只清理表达，**不新增也不验证事实**；金句只保留在"纠正真实自责"的句子。

## 视觉方向
- **原则**（取自对 Sara Hagale 式简笔画的观察，已核实她是真人、Instagram 25 万+粉丝）：铅笔质感、米白纸、很少的线条、表情传情、留白。**不在提示词里写她的名字**，不复制构图和角色，出图后对照避免近似。
- **"信息过载 → 偏爱粗糙"这个论断没有直接证据**（手作效应、手写字体的实验只是间接支持；见 `research/visual-style-evidence-2026-10-05.md`）。
- **一个真实的矛盾**：粗糙画风的魅力来自"这是一个人画的"，而 AI 披露会降低真实性、欣赏度和购买意愿（多项研究摘要级结果）。"AI 模仿手绘 + 标注"会怎样，**未知**。
- **选项（待用户定）**：A 接受标注，直接测读者反应；**B 猫头像由用户本人画**（照自家猫的照片描），AI 只做各物种插画（我的倾向：成本最低、符合"真诚"、保护产品基座）；C 先用极简线条加文字为主。
- 现状：`tools/sketch.py` 能画代码绘制的铅笔占位图（旧样稿用过，在 `content/posts/archive/`），**不是 AI 生图**；正式图等 P1。

## 变现：初期 ¥500/月
- 算术（单价是假设，不是行业数据）：到手 ¥10/单 → 50 单；¥20/单 → 25 单。**没有这个赛道的转化数据**，前期要测"每千次阅读有多少人明确想要产品"。
- 顺序（按前置成本）：**电子壁纸/月历 → 微信表情（赞赏）→ 实体贴纸**。内容与表情包契合：讲边界、慢热、陪伴的内容，对应人在聊天里想表达的情绪（我的推断）。
- "达成"的定义（建议）：**任一自然月到手 ≥ ¥500**；之后再看能否连续三个月。
- 都依赖 AI 图：微信表情、小红书店铺对 AI 素材的要求**我没有核实到**。AI 图的版权判法不一，商用图保存提示词和迭代记录（见 `docs/07-animal-direction-feasibility.md`）。

## 小红书"爆款原理"
我查到的全是二手资料且互相矛盾，**没有一个有官方出处**。只当待验证的假设：评论/收藏/关注比点赞更值钱；封面和标题决定点击；情绪陪伴是趋势。详见 `research/xhs-viral-principles-2026-10-05.md`。**真正可靠的是账号后台的数据。**
