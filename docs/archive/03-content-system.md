# 03 · 内容生产与发布

> **已归档（2026-10-06）**：属于已被取代的旧路线或旧版论述，仅作历史参考，不要按它做事。现行路线见 `docs/08-route.md`。


## 一篇笔记 = 一个「选题 → 卡片 → 正文」

```bash
python tools/build_pool.py                                 # 解析上游，生成 content/pool.json
python tools/make_post.py --list --risk low --ratio 极高    # 看候选
python tools/make_post.py --slug save-01 --title "这3种钱别花" 05-06 05-45 14-01
python tools/render_cards.py content/posts/save-01.json     # → output/save-01/*.png
```

然后：打开 `content/posts/save-01.caption.md`，**自己写开头和结尾**，再过下面的检查清单。

## 选题优先级（`pool.json` 的 `score` 已按此排序）

性价比「极高」（成本≈0、收益大）> 「高」；证据 A > B > C；章节风险 low > medium > high；带"争议"的降权。
**首批 20 篇只用 `risk=low`**：第 3、4、5、6、7、11、14、21、22、23、26、31、32 节。这个风险分级是我对平台审核倾向的判断，不是官方名单。

## 一篇笔记的结构

| 位置 | 内容 | 备注 |
|---|---|---|
| 封面 | 大标题（≤10 字最佳）+ 猫 + 3~5 个字的钩子 | 第一眼要能看出"有用" |
| 卡片 1–N | 每条 = 标题 + 说人话 + 成本/证据属性栏 | 3~5 条/篇，7 张以内 |
| 正文 | 1) 你自己的一句话切入 2) 条目清单 3) 一个问题引评论 4) 署名与免责 | ≤ 1000 字 |

标题 ≤ 20 字。标题公式（候选，测哪个好用看数据，不是定论）：`数字 + 动作 + 对象`（"这3种钱别花"）、`反常识`（"越便宜越贵的5件事"）、`人群 + 痛点`（"刚工作别踩这3个坑"）。

## 每篇必须有的"你自己的增量"

至少一条：你亲身验证过 / 加拿大对应做法 / 你踩过的坑 / 你对这条的保留意见。**写不出就别发这篇**——这是区别于搬运的底线，也是平台和读者会奖励的东西。

## 发布前检查清单

- [ ] 署名行在正文和每张卡片上（CC BY 4.0 强制）
- [ ] 卡片文字全部来自上游「说人话」，没有自己加数字/症状/结论
- [ ] 涉及大陆法规/政策的条目，我或你去原文核过当前仍有效
- [ ] 不是 `medium/high` 章节；若是，已读原条目备注，没有"争议"开头
- [ ] 无诊断、用药、投资、法律结论性措辞（改成"上游书提供的证据是…"）
- [ ] 用了 AI 生成的图/文 → 主动标注（见下）
- [ ] 标题 ≤ 20 字，没有绝对化用语（最/第一/一定/100%）
- [ ] 手动发布，不用 `publish_*` 工具
- [ ] 记一行到 `research/posts_log.csv`

## AI 内容标注（平台规则，要核对官方）

检索到的媒体报道称：小红书 2026 年发布了 AI 内容治理规则，鼓励/要求对 AI 生成内容主动标注，未标注的会被自动识别，违规按梯度处置（限流 → 禁言 → 封号），并反对用云端 AI 工具/手机脚本自动运营账号。**各来源对生效日期和处罚细节说法不一**（2 月公告 / 7 月生效），以平台官方公告为准，发布前去创作者中心确认。我的处理：猫是脚本绘制的矢量图、文字来自上游，但你改写的正文如果由 AI 辅助生成，稳妥起见标注 AI 辅助。

## 节奏

起步每周 3–4 篇，固定时段。先求稳定，再看数据调整。重点是 20 篇后复盘，不是前几篇出爆款。

## 复盘（每 5 篇一次）

对比：收藏/点赞/评论/涨粉，按章节、标题公式、封面表情分组。记在 `research/posts_log.csv`，不要只凭感觉。
