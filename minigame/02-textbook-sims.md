# 路线：教材知识点 → PhET 式互动模拟（小红书小工具）

日期：2026-10-10。Chris 的计划：按人教版中小学教材的知识点做互动模拟，形式参考 PhET，目标是被引用（老师上课用、家长给孩子玩）。

## 判断

方向成立，而且比之前的三个方向更有沉淀价值。小工具的限制正好适合模拟器：纯本地 HTML、不能联网、单包 10MB。PhET 本身就是离线 HTML5 页面。

但有三个前提要先定下来：

### 1. 只用「知识点」，不用「教材本身」
- FreePEP 只是下载器（MIT），不带教材文件。它的 README 自己写着：教材版权归人民教育出版社，严禁商用，建议下载后删除。
- 知识点、公式、科学事实不受著作权保护；受保护的是教材里的文字、插图、例题、版式。（这是著作权法「保护表达、不保护思想」的一般原则，具体边界我不是律师，不确定。）
- 所以做法应该是：**知识点按公开的《义务教育课程标准（2022 年版）》来组织**，教材只作为「对应第几章」的索引来参考。不复制课文、插图、例题，不用人教社的标识，也不做成「人教版官方」的样子。
- 结论：大概率不需要用 FreePEP 批量下载 780 本教材。需要对照章节时，看人教社平台的在线版就够了。

### 2. PhET 只当参照，不搬
- 2026-03-29 之前发布的 PhET HTML 模拟是 CC BY 4.0，可以商用，但必须署名。PhET 的商标不在授权范围内。修改模拟本身是否允许，页面没写清楚，未知。之后发布的版本适用另一套条款，未读。
- 结论：只学它的交互原则（可拖动、即时反馈、少字、让人自己发现规律），模拟全部原创。

### 3. 要被老师引用，光有小红书不够
- 小工具只能在小红书 App 里打开，老师在教室投屏不方便，也没法在教案里贴一个链接。
- 建议同一份 HTML 发两处：小红书小工具（传播）＋ 自己的静态网站（引用和上课用）。国内能不能稳定访问取决于托管位置，未验证。

## 风险
- **准确性**：教育内容错了会直接伤信誉。AI 写的物理/数学模拟可能有公式或单位错误，每个都要逐条对照课标和可靠来源核对，按 CLAUDE.md 第三档严谨度处理。
- **钱**：小工具仍然没有直接收入，「被引用」是声誉资产，变现路径要另想（未定）。
- **存档**：模拟器基本不需要存档，这条风险反而消失了。
