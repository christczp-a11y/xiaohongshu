# 模拟 02：水去哪儿了（水循环）

日期：2026-10-10。状态：第一版已完成，作为 `minigame/STYLE.md` 的参照实现。

## 学习目标（玩完能说出来的）
1. 太阳把湖水晒热，水变成水蒸气升上天（蒸发）。太阳越高，蒸发越快。
2. 水蒸气在高处变冷，凝成小水滴，聚在一起就是云（凝结）。
3. 云里的水滴越聚越多、越来越重，就落下来变成雨（降水）。
4. 雨水顺着山坡汇成小河，流回湖里（汇流）。水一直在转圈。

对应课程：小学科学中关于水循环的内容。具体年级和课标条目**待核对**（课标原文还没读到）。

## 交互
- 拖动「太阳时间」滑杆（4:00–20:00）：太阳东升西落，蒸发速度随太阳高度变化，夜里停止。「播放」会让时间自动走。
- 拖动云朵：把云挪到别处，雨就下在那里。
- 按住云朵不放：把雨挤出来。云攒满了水也会自己下雨。
- 读数卡显示湖里、云里、山坡上的水量。按「重来」恢复初始状态。

## 简化（页面上已注明第一条）
- 水蒸气本来看不见，这里画成白点。
- 只画了湖面蒸发，没有画植物蒸腾，也没有画地下水。
- 水量用抽象单位，系统内守恒：蒸发减少湖水，雨水再还回去。数值不对应真实数量。
- 云的灰度表示「云更厚」，不表示真实的水滴大小。

## 技术
- `src/terrain.ts`：地形高度函数（纯函数）。`src/terrain.test.ts` 检查湖底低于最低水位、湖外陆地高于最高水位、河流往下游走。
- `src/main.ts`：场景、粒子、交互和界面。
- `npm run build`：打成约 0.6MB 的单文件网页，给网站用。
- `npm run minitool`：打成小红书小工具包（`scripts/build-minitool.mjs`），zip 约 0.2MB，里面是 `index.html`、`main.js`（经典脚本，ES2017）、`style.css` 和 `fallback.webp`（不支持 3D 时显示的静态图）。
- 画质分三档，按实测帧率自动往下降；`?stats` 可以显示每帧的 draw call 和三角形数。
